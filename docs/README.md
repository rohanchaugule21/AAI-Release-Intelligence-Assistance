## Repository Overview

The AAI Release Intelligence Assistant enables users to query release information using natural language.

Supported capabilities include:

- Release Search
- Story Search
- Component Search
- Dependency Analysis
- Trend Analysis
- FastAPI APIs
- Streamlit User Interface
